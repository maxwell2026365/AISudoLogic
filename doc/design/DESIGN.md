# AISudoLogic 数独游戏 · 设计文档

> 一款支持 **macOS** 与 **iOS** 的双平台数独游戏。
> 技术栈:SwiftUI + SwiftData,无第三方依赖。

- **平台**:macOS 15.7+ / iOS 26.1+
- **功能范围**:标准版(难度选择、填数、笔记、撤销、提示、错误检查、计时)
- **进度保存**:SwiftData 持久化,自动恢复未完成的一局
- **视觉风格**:原生 SwiftUI 简洁风,自动适配深浅色

### 交互要点

- 点选格子 → 高亮选中格 + 同行/列/宫淡色高亮
- 点数字 → 填充;若该数字已错 → 显示红字 + 计入错误次数
- 笔记模式(铅笔) → 点击数字填入候选记号(小字),重复点击可切换开/关
- 长按/选中已填格 → 高亮棋盘上所有同数字格子
- 提示 💡 → 高亮一个可填正确数字的正确格

## 二、技术方案

### 技术栈

- **SwiftUI + SwiftData**(项目已就绪,不引入第三方依赖)
- 部署目标沿用项目现有配置:macOS 15.7 / iOS 26.1(可直接用 `@Observable`、`@Model`)
- 核心算法是纯值类型,天然可单元测试

### 数据模型

```swift
enum Difficulty: String, Codable, CaseIterable { case easy, medium, hard, expert }

/// 纯值类型,可 Codable 序列化存盘
struct SudokuPuzzle: Codable {
    var cells: [Int]         // 81 格,0 = 空
    var givens: [Bool]       // 题目给定(不可改)
    var solution: [Int]      // 唯一完整解(供提示/校验)
    var notes: [[Set<Int>]]  // 每格笔记(铅笔)
    var difficulty: Difficulty
}

/// SwiftData 持久化:只存一局,退出自动恢复
@Model final class GameSession {
    var puzzleData: Data          // SudokuPuzzle 编码
    var elapsed: TimeInterval
    var errors: Int
    var moveHistory: Data         // 撤销栈(移动快照,上限 ~100)
    var isCompleted: Bool
    var startedAt: Date
}
```

- 撤销用**移动级快照**:记录 `(格子, 旧值, 旧笔记)` 差分,比存整局轻量
- 菜单页查询是否有未完成的 `GameSession` → 显示"继续上次游戏"

### 核心算法(`Services/`)

| 模块 | 说明 |
|---|---|
| `SudokuSolver` | 回溯 + MRV 剪枝(最少候选格优先)。用于生成验证和提示 |
| `SudokuGenerator` | ①随机回溯生成完整解 → ②按难度挖洞,每挖一格用 solver 验证**唯一解**,直到达到目标空格数 |
| 难度参数 | 简单 ~40 / 中等 ~50 / 困难 ~56 / 专家 ~58 空(唯一解保证) |

### 状态管理(`GameViewModel`)

`@Observable` 单例,由 `AISudoLogicApp` 注入环境。核心状态:当前格、笔记模式、选中数字、错误计数、撤销栈、计时。所有动作(填数/擦除/笔记/撤销/提示)集中在此,便于测试与持久化。

### 跨平台适配要点

- **iOS**:`NavigationStack`,棋盘全屏,数字键盘在底部,安全区适配
- **macOS**:可缩放窗口(用 `GeometryReader` 等比放大棋盘),支持实体键盘输入(1-9、方向键移动、⌫ 擦除);顶部仍保留可点的数字键盘供鼠标用户
- **计时**:`scenePhase` 监听退到后台自动暂停;从 `startedAt + elapsed` 恢复
- **动画/反馈**:填充和删除用轻量 `withAnimation`,错误格轻微抖动

### 实现步骤(里程碑)

1. **数据模型 + 算法**:`SudokuPuzzle`、solver、generator,配单元测试(生成结果唯一解、难度空格数达标)——全项目地基
2. **棋盘视图**:9×9 网格、3×3 粗边框、给定/玩家格子着色
3. **游戏状态机**:选中、填数、错误检测、数字高亮联动
4. **工具功能**:笔记模式、撤销/重做、擦除、提示、计时
5. **菜单 + 难度选择**:切到 SwiftData 生成新局
6. **完成检测 + 弹窗**:胜利判定、用时统计
7. **SwiftData 持久化**:保存/恢复、暂停恢复、完成归档
8. **macOS 适配**:键盘输入、窗口缩放、macOS 专属布局
9. **打磨**:动画、无障碍标签(每格 `accessibilityLabel`)、深浅色
