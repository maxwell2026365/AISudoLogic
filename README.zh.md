# AISudoLogic

一款支持 **macOS** 与 **iOS** 双平台、融合大模型 AI 能力的数独游戏。

---

## 一、项目解决的问题

传统数独游戏通常只有"填数 - 检查 - 完成"的单一流程,玩家在遇到难题时缺少有效的引导。AISudoLogic 解决的核心问题:

1. **卡关无助** —— 玩家面对复杂盘面时,不知道下一步该填什么、为什么。
2. **缺乏学习引导** —— 传统游戏直接给答案或只做简单判断,不讲解数独技巧(唯一候选、排除法等)。
3. **体验枯燥** —— 只有普通对局,缺少成就、挑战、数据反馈等留存机制。
4. **跨平台割裂** —— 同一游戏在 macOS 与 iOS 上体验不一致。

## 二、项目如何解决

**1. 完整的数独核心引擎**
- 纯 Swift 实现的数独生成器与求解器
- 四档难度(简单 / 中等 / 困难 / 专家),通过"挖洞 + 唯一解验证"保证每局都有唯一解
- 回溯 + 最少候选优先(MRV)求解算法,毫秒级求解

**2. AI 大模型深度融入**
- **AI 突破点提示**:本地算法先精确定位"唯一候选 / 排除法"突破口,再由 DeepSeek 大模型用通俗语言解释推理过程(关闭思考模式,即时响应),并以 Markdown 渲染展示
- **AI 教练对话**:接入 DeepSeek API,支持流式逐字输出,提供:
  - 💡 下一步思路分析
  - 📊 盘面难度评估
  - 🎯 针对性技巧练习
  - 🧭 基于历史记录的个性化推荐
  - 💬 自由自然语言对话

**3. 成就与留存系统**
- **统计面板**:按难度统计通关数、胜率、无错误胜率、最短/平均通关时间、当前连胜
- **每日挑战**:每天按日期种子生成固定题面,完成获得奖杯 🏆

**4. 精致的双平台体验**
- 棋盘自动撑满窗口宽度,行列号对齐,自适应不同屏幕
- 深色主题,深浅色模式统一
- 柔和的马卡龙色宫格,动画反馈
- 进度自动保存(SwiftData),退出恢复

## 三、与其他数独游戏的亮点对比

| 亮点 | 说明 |
|---|---|
| 🤖 **AI 教练式引导** | 不只是给答案,而是讲解"为什么填这里"、用了什么技巧,像真人教练一样 |
| ⚡ **本地算法 + AI 结合** | 先由确定性算法定位突破口(保证正确),再让 AI 解释推理——快且准 |
| 🎯 **个性化推荐** | 基于你的通关历史,AI 推荐适合你的难度与练习方向 |
| 🏆 **每日挑战 + 奖杯** | 每天一题固定题面,与全球玩家同步,完成即得奖杯 |
| 📊 **深度数据统计** | 胜率、无错误率、连胜、用时等,见证成长 |
| 🧠 **针对性训练** | 针对卡住的技巧(X-Wing 等)专项讲解与练习 |
| 📱 **双平台一致** | macOS 支持键盘输入,iOS 触屏适配,体验统一 |

## 四、如何启动游戏

**环境要求**
- Xcode 15.7+ / macOS 14+
- DeepSeek API Key(可选,用于 AI 功能;不配置则仅使用本地算法)

**方式一:Xcode 运行**
```bash
# 打开工程
open AISudoLogic.xcodeproj
```
在 Xcode 中选择 AISudoLogic scheme,选择目标设备(macOS 或 iOS 模拟器),点击 ▶ 运行。

**方式二:命令行双平台部署**
```bash
./doc/sh/run_all.sh
```
该脚本会自动构建并同时部署到 macOS 与 iPhone 17 Pro Max 模拟器。

**配置 AI 功能(可选)**
1. 在 AI 教练对话框中点击 🔑 图标
2. 填入 DeepSeek API Key 与模型名(默认 `deepseek-v4-flash`)
3. 保存后即可使用 AI 提示与 AI 教练
